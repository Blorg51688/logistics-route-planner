# 测试用例表

> 本表是《数据结构课程设计》报告【测试】章的备料，用户写报告时自行取用。
> 每条用例给出：**用例 → 输入 → 期望结果（标口径）→ 依据**（哪个测试文件里的哪个检查、或哪条命令的实测输出）。
> 本表不替代 `docs/设计.md` §14（测试分层与期望值来源），那边讲「为什么这么测」，这里讲「测了什么」。

## 口径说明（先读，**三套口径不许混**）

| 口径 | 数值（2026-11-24 实测） | 怎么来的 |
|---|---|---|
| `ctest` 目标数 | **16** | `cd build && ctest -N` 报 `Total Tests: 16`（9 个单元/集成二进制 + `oracle_selfcheck` + `dataset_selfcheck` + `doc_links_lint` + `cli_dump_graph` + `cli_action_self_check` + `cli_ui_probe` + **`cli_plan_summary`**；Qt6 缺失时 GUI 相关自动跳过） |
| ① C++ 二进制自报项数 | **2273** | 9 个二进制**各自自报**的检查数之和：`core` 101 + `config` 654 + `minheap` 28 + `simevent` 53 + `dijkstra` 19 + `routeplanner` 904 + `integration` 381 + `traffic` 99 + `graphedit` 34，全部 **0 项失败** |
| ② 摘要守卫项数 | **162** | `cli_plan_summary` 自报「162 项检查，0 项失败」（跑真二进制读 `--plan-summary` 四行 + 13 字段 × 3 策略 + oracle L3 对拍） |
| ③ 交互自检条数 | **79** | `--self-check-actions` 的 `[self-check] OK` 行数（另含汇总行与少量 `--` 信息行，**不要把总行数当条数**） |

**这三组数不能相加、不能互相替代**：16 是 ctest 的执行目标数；2273 / 162 / 79 是三种**不同载体**的断言计数。
本表「依据」列标注的口径含义：**已提交基线** = 在 `HEAD`（`git rev-parse HEAD`）上可复现；**工作区未提交修订** = 含工作区未提交改动的实测。

> 当前实测（2026-11-24，分支 `spec/pdp-fleet`，HEAD `cdc98e2`）：
> `ctest` **16/16** 通过（81.54s）；9 个二进制全部「0 项失败」合计 **2273** 项；`cli_plan_summary` **162** 项；`--self-check-actions` **79 条 OK / 0 FAIL**。
