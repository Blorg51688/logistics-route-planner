# 异构车队：两型车、每车标量因子与「完工耗时」口径

**Status**: accepted（2026-11-23）

**Related**: wayfinder map #16 / issue #19（规格二 · 异构车队模型）；术语见 [`GLOSSARY.md`](../../GLOSSARY.md)。本决定替代 #23 resolution 中「`[vehicles]` 保持 4 列不动」的规格一阶段性口径（迁移归 #20）。

## 背景与决定

规格二（P2Q1）拍板异构编队。本票把车队模型定稿为：

1. **两型车、每车一行 6 列**：`ID, start_node, capacity_kg, depart_time, time_factor, cost_factor`；默认 V01 快车（400kg / 1.00 / 1.50）+ V02/V03 慢车（160kg / 1.25 / 0.80），全部 W01、08:00 发车。
2. **因子是每车统一标量**：耗时 = 边**当前**耗时 × `time_factor`（拥堵后），成本 = 边成本 × `cost_factor`，**距离不变**；等待（早到等窗口）与 penalty **不乘**因子。
3. **每车一条连续路线**：从自己的基地空载出发、回同一基地；一单由一台车全程完成（跨车转运归 #28）。
4. **指标按车记、车队汇总**：每车五项（距离/耗时/成本/penalty/停靠数）；车队「总耗时」主口径 = **完工耗时**（最晚回基地 − 最早发车），另列 **车时合计**（Σ 每车耗时）。
5. **GUI 每车一页签**，页内「固定信息 / 运行状态」两块；页签标题 = 车辆 ID + 容量。
6. **160kg 零余量按「例外非常态」**：默认三批次 160/144/152kg 各由一台车完成（回程单先取、到枢纽先卸后装），不需要拆批/降载/转运；备用参数（慢车 180/200）只在实测频繁触发时回退，不预置新机制。

## 为什么（非显而易见的取舍）

- **为什么 `time_factor` 而不是 `speed_factor`**：票面的 1.25 表示「慢 25%」，若叫 speed_factor（越大越快）会长期读反；time_factor 与数值方向一致，与 cost_factor 同构。
- **为什么因子作用在拥堵后**：拥堵按比例拖慢所有车，慢车在同样拥堵下也按比例更慢。若作用在基础耗时、拥堵增量按绝对分钟叠加，快慢车的拥堵增量会相同，物理上说不通，还要维护两套时间口径。
- **为什么是标量而不是按路段/载重变化**：保持模型与验收简单。标量因子**不改变**单车内的最短路 leg 选择（所有权重同乘一个正数，argmin 不变），但**会通过到达时刻/penalty 改变停靠顺序**，所以必须用缩放后的耗时**重放**，不能「先排路线、再缩放指标」。
- **为什么总耗时用完工耗时**：与单车耗时同量纲，可直接沿用「总耗时 ≤ 12 小时工作日」不变量；Σ 车时约 3 倍，容易被误读成「更慢了」。车时合计保留作工作量参考。
- **为什么每车一行而不是 `[vehicle_types]` + count**：单一形状、无重复真值、错误行号可定位；代价是两台慢车重复写同样因子，接受。
- **为什么保留 160kg 零余量**：按本人裁决原则（最终呈现优先、杜绝复杂机制）。默认数据每个子网络恰好一个枢纽批次，一台车一批次即可（回程单先取、到枢纽先卸后装，峰值分别 160/144/152）；拆批/降载/转运因此是**例外**。若实测默认三策略频繁因容量触发，才回退慢车 180/200，不为「看起来真实」预先加机制。

## 备选（已否决）

- `speed_factor` 命名，或让 1.25 表示「快 25%」（与票面数值冲突）。
- 4 或 6 列兼容；7 列加 `class`；`[vehicle_types]` 归一化 + `count`。
- 因子作用于基础耗时、拥堵增量按绝对分钟叠加。
- 总耗时 = Σ 车时为主口径；只给每车指标、不给车队汇总。
- GUI 车辆选择器 + 两页签；两页签车队表；每车两页签。
- 预置慢车 180/200（保留为实测后的回退）。

## 关键约束

- `[vehicles]` 严格 **6 列**，旧 4 列按字段数报错（迁移 #20）；至少 1 行；ID 非空唯一；起始节点必须是仓库；容量 > 0；发车 `HH:MM`；两个因子为**有限正实数**。
- 图表示（邻接矩阵 / 邻接表 / 权重标签）仍显示**基础边权**，不按车缩放。
- 每车指标之和必须对齐车队汇总（距离 / 成本 / penalty / 停靠数）；**完工耗时与车时合计不可混同**。
- 默认车队全从 **W01** 发车；W02 仍是普通节点（跨仓库调度在 Out of scope）。
