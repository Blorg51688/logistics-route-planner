## 七、本轮待实现清单（要求核心/扩展明文提到 + 用户裁定）

> 详细验收口径见 `docs/设计.md` §16。

| 阶段 | 内容 | 依据 |
| --- | --- | --- |
| **P0** | 数据层：单向路（D18）、无向道路对数 ≥50（D19）、中转站归属配送点（D17）、重新生成并更新黄金值 | 设计 §4.2 / §8.4 |
| **P1** | **core：多趟与中转集散**——`TransitStock`、`RoutePlan` 改趟列表、簇划分 + 贪心装箱 + 补给/二次配发状态机、**移除 `OverCapacity` 判定**、6 条不变量测试 | 设计 §5.5 / §5.6 |
| **P2** | core：增量式重规划（只重算受影响段；断言与全量结果一致） | 设计 §5.7 |
| **P3** | 子网络 `sub_network_id` 接上行为 | 设计 §4.1 |
| **P4** | UI：**中转站暂存货量显示**、多趟路线呈现、路线面板增加趟数与暂存/峰值 | 设计 §4.6 |
| **P5** | 测试与人工向导：改写载重关卡、新增暂存守恒/单向路/增量一致性关卡、同步黄金值 | 设计 §14 |

**关于"效率"的说明**：设计文档已明确要求**不得宣称不实收益**——
在单车单仓库模型下，中转站集散**不必然降低总距离**（干线里程下界相同）。
其价值是使**超载场景从不可行变为可行**、免除每趟空驶回仓库，
并为将来多车提供枢纽。报告中应以「可行性 + 趟数 + 总权重」评价，而非"更省距离"。
