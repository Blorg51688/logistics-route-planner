## 归档的判据（三条都满足才移进来）

1. **内容已过时**：描述的现状与当前实现不符，或结论已被后续决策取代；
2. **无承重引用**：没有别的文件依赖它的事实（移进来不会让任何链接失效）；
3. **仍有留存价值**：删掉就丢了"当初为什么这么定"的信息。

第 2 条最要紧：本项目的 `doc_links_lint` 守卫会逐条校验 `docs/` 里的相对链接，
**任何搬动导致链接失效都会让 `ctest` 变红**——所以归档只能选"无主"的文档。

---

## 新增归档的规矩

1. 用 `git mv` 移动（保留文件历史，不要 `rm` + 新建）；
2. 同步改掉**全部**引用（`grep -rn "旧路径" --include="*.md" .` 确认无残留）；
3. 在 [`文档导航.md`](../文档导航.md) §二 保留指路行，状态标 `⚠️ 历史文档（已归档）`；
4. 本文件夹是**历史陈列**，不是当前真相——需要当前事实时请看 `docs/设计.md` 与 `docs/项目速懂.md`。
