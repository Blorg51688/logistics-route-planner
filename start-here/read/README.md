# 要看 —— 需要你读的文档

本文件夹**不放文档副本**，只给导览。原因很实在：`docs/` 下的文档互相链接、全部被 git 跟踪，
复制一份必然与原文漂移（原文一改，副本就成了假真相源）。所以下面**一律指向原文**。

---

## 读什么、按什么顺序

| 顺序 | 文档 | 读完你应该能回答 |
|---|---|---|
| ① | [`项目速懂.md`](项目速懂.md) | 用什么数据结构承载数据、为什么这么选、结构怎样支撑调度、代价多大 |
| ② | [`docs/设计.md`](../../docs/设计.md) | 冻结决策 **D1–D24**、领域模型、算法语义、模块边界（重点是 §2 / §4 / §5 / §6 / §10） |
| ③ | [`docs/功能实现清单.md`](../../docs/功能实现清单.md) | 每条课程要求**做到没有**、在哪儿、怎么验证 |
| ④ | [`docs/课设要求整理.md`](../../docs/课设要求整理.md) | 老师要什么：题目、报告结构、排版、评分构成、检查时间 |

想先看项目的门面（怎么安装、目录结构、常用命令）→ 根目录 [`README.md`](../../README.md)。
想找**全部**文档与待完成清单 → 根目录 [`docs/文档导航.md`](../../docs/文档导航.md)（单一真相源）。

## 读的时候注意三件事

1. **`docs/设计.md` 的 §2 / §4 / §5 正文里夹着大量"注（2026-09-26）"**，它们推翻了正上方的原文
   （中转站暂存、二次配发、集散排线、`stock[t]` 不变量都已移除）。**只读没标注的段落会读到已废弃的机制。**
2. **`docs/人工测试记录.md` 是陈旧记录**，不可当证据；只能由真人跑向导刷新，不许手改。
3. **`docs/screenshots/` 已过期**，别拿旧截图讲界面。

这两类"过时"事实的完整清单，见 [`项目速懂.md`](项目速懂.md) 第 11 节「口径与别踩清单」。
