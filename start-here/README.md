## 三个子文件夹

- **`read/`** —— 你要读的文档：[`项目速懂.md`](read/项目速懂.md)（图版主文）、[`数据结构总览.html`](read/数据结构总览.html)（结构之间怎么连通）、[`项目结构图.html`](read/项目结构图.html)（模块与依赖边界，均浏览器双击打开、自包含）。
  完整推导、七栏感性表、追问答法等备查内容在 `docs/`（`项目速懂-详解.md`、`数据结构地图.md`），不重复放在用户区。
- **`run/`** —— [`启动软件.sh`](run/启动软件.sh)，薄封装（`exec` 项目根的同名实现）。改行为请改实现，不要改入口。
- **`deliverables/`** —— 报告、流程图、UML、测试用例表的成品出口，见 [`deliverables/README.md`](deliverables/README.md)。

## 读的时候注意三件事

1. **`docs/设计.md` 的 §2 决策表与 §4/§5/§6 里保留着历史段落**（多趟分批、仓库装货、缓冲库存、并集窗口），
   它们都带「已由规格一取代」或「注（2026-09-26）」标记。**只读没标注的段落会读到已废弃的机制**；
   现行口径见设计 **§4.7「实施期口径精确化」**（10 条偏离台账）。
2. **人工测试向导与记录已于 2026-11-17 退役**；定位问题用常规启动 + `--self-check-actions` / `--ui-probe`。
3. **`docs/screenshots/` 的截图已过期**（界面改过状态栏时间、顶栏拆成 5 条、车辆信息分页签）。
   需要重截：`QT_QPA_PLATFORM=offscreen ./build/app --render-window docs/screenshots/gui-window.png`。
