## 三个子文件夹

- **`read/`** —— 你要读的文档：[`项目速懂.md`](read/项目速懂.md)（图版主文）与 [`数据结构总览.html`](read/数据结构总览.html)（结构之间怎么连通，浏览器双击打开，自包含）。
  完整推导、七栏感性表、追问答法等备查内容在 `docs/`（`项目速懂-详解.md`、`数据结构地图.md`），不重复放在用户区。
- **`run/`** —— [`启动软件.sh`](run/启动软件.sh)、[`人工测试向导.sh`](run/人工测试向导.sh)。向导本体在 `scripts/`；
  `启动软件.sh` 是薄封装（`exec` 项目根的同名实现），`人工测试向导.sh` 的实现就在本目录。改行为请改实现，不要改入口。
- **`deliverables/`** —— 报告、流程图、UML、测试用例表的成品出口，见 [`deliverables/README.md`](deliverables/README.md)。
